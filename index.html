Misi Logika Game Edukasi Computational Thinking — SMK Kelas X

Misi Logika: Berpikir Komputasional

Petualangan 2D Platformer Edukasi: jelajahi dunia Cozy Pixel Art, lompati rintangan, hadapi monster, dan taklukkan 3 Gerbang Soal pada materi Sequential, Bubble Sort, dan DOS!

Halo, Siswa Kelas X SMK!

Gunakan A / D untuk bergerak dan W / Space untuk melompat. Kumpulkan koin, aktifkan Checkpoint, dan buka 3 gerbang materi di tiap stage untuk mencapai Finish!

Pilih Tingkat Kesulitan (Nyawa / HP)

Mode Normal: 5 HP (Nyawa) seimbang untuk petualangan platformer & tantangan logika.

Navigasi Materi Pembelajaran (3 Stage)

STAGE 1

Algoritma Sequential

Urutkan 20 kegiatan sehari-hari menjadi langkah yang logis dan runtut.

STAGE 2

Algoritma Bubble Sort

Bandingkan dua objek bersebelahan lalu tukar atau pertahankan posisinya.

STAGE 3

DOS Command Line

Praktik perintah MD, DIR, CD, COPY CON, COPY, REN, DEL, hingga RD.

Status Progres: Belum ada progres tersimpan
Konfirmasi Reset

Reset Progres Belajar?

Semua skor dan progres di Stage 1, Stage 2, dan Stage 3 akan dihapus. Tindakan ini tidak bisa dibatalkan.
